## push を保留している理由（引き継ぎ）

`stage0-spec-cleanup-fixes` は GitHub の公開リポジトリのブランチである。
昨夜の merge は「採否は先生の判断」と私が明示的に留保した件で、その承認を
**同僚セッション経由の伝聞**で受けた。ローカルの merge までは進めたが、
**公開は先生の直接の指示を待つ**。

- 出すとき: `git push`
- 取り消すとき: `git reset --hard ORIG_HEAD`

今日の run の成果も同じ扱いにする。**s3 の `autoresearch/nightly` に積み、merge も push もしない。**
