R-WHILE とは

R-WHILE は、可逆計算の理論研究を目的として設計された最小限の可逆プログラミング言語です。 Janus が整数を扱うのに対し、R-WHILE はすべてのデータを木構造（二分木）で表現します。

R-WHILE は可逆チューリング完全であることが証明されており、 任意の可逆計算をR-WHILEプログラムとして表現できます。 さらに、R-WHILE で書かれた可逆自己インタプリタ（自分自身を解釈実行するプログラム）が存在することも示されています。

理論的な重要性：R-WHILE は、可逆計算の理論的限界を探るための「実験室」として機能します。 最小限の構文で可逆チューリング完全性を達成しているため、可逆計算の本質的な構造を研究するのに適しています。

データ構造：木（ツリー）

R-WHILE のデータはすべて二分木です。基本的なデータ型は以下の3種類です。

型構文説明
nilnil空の木（何もないことを表す）
atom'a, 'hello, '32アトム（名前付きの葉ノード）
cons(A . B)二分木の節（左の子 A と右の子 B）

例えば、リスト [1, 2, 3] は ('1.('2.('3.nil))) と表現されます。 自然数 N は nil を N 個入れ子にした木 (nil.(nil.(nil.nil)))（= 3）で表現できます。

サンプルプログラム

例1：Swap（2要素の交換）

read X;
  cons Y Z <= X;
  X <= cons Z Y;
write X
入力: ('a . 'b)
→
出力: ('b . 'a)

例2：Reverse（リストの反転）

read Y;
  from =? X nil loop
    (cons Z Y) <= Y;
    X <= (cons Z X)
  until =? Y nil;
write X
入力: ('1.('2.('3.nil)))
→
出力: ('3.('2.('1.nil)))

このプログラムを逆変換すると、入力と出力が入れ替わった逆プログラムが自動的に得られます。 逆プログラムは反転されたリストを元の順序に戻します。

例3：Minus（引き算、マクロ使用）

macro MINUS(X,Y)
  from =? Y' nil
  loop cons nil X <= X;
       cons nil Y <= Y;
       Y' <= cons nil Y'
  until =? Y nil;
  Y <= Y'

read Z;
  cons X Y <= Z;
  MINUS(X,Y);
  Z <= cons X Y;
write Z
入力: (4 . 3)
→
出力: (1 . 3)

メタプログラミング拡張 第2弾：理論的完全性の実証

第2弾では、可逆計算理論の中核的定理を実証する5つの拡張を実装しました。 これらは「可逆メタプログラミングの理論的完全性」を示す統一的な物語を形成します。

1. smn定理 — 可逆カリー化

プログラム P(x,y) と値 a が与えられたとき、Pa(y) = P(a, y) を計算するプログラムを 効果的に構成できることを示す定理です。R-WHILEでは Pa も可逆でなければなりません。

理論的意義：smn定理 + 万能関数(ri) = r-Turing完全性（Jones, 1997）。 可逆計算が通常の計算理論の基盤を満たすことの中核的証明です。

実装方法：プログラム変換によるペア構成。Pa は入力 y を受け取り、 CRep命令を用いて可逆的に (a . y) を構成し、Pの本体を実行します。

(* smn(swap, 'a) が生成するプログラム *)
read SDYN; (* y を読む *)
  STMP ^= 'a; (* 静的引数をセット *)
  X <= cons STMP SDYN; (* X = ('a . y), STMP=nil, SDYN=nil *)
  (* swap の本体 *)
  cons Y Z <= X;
  X <= cons Z Y;
write X (* 結果: (y . 'a) *)

検証済み性質：正当性（eval(Pa, y) = eval(P, (a.y))）、 可逆性保存（inv(Pa) が y を復元）、 identity・swap・reverse の各プログラムで確認。

2. ステップ計数インタプリタ — 線形時間自己解釈の検証

R-WHILEの自己インタプリタ ri は、プログラムPの実行を O(T) ステップでシミュレートします （T は直接実行のステップ数）。通常の自己インタプリタが少なくとも O(T²) のオーバーヘッドを持つのに対し、 R-WHILEの構造が O(T) を可能にしています。

理論的意義：線形時間自己解釈は r-Turing完全性の証明に不可欠です。 オーバーヘッドが定数倍であることは、メタプログラミング塔全体の実用性を保証します （Glück & Yokoyama, 2016）。

3. 逆解釈合成 — 4経路入力復元定理

プログラムPと入力vが与えられたとき、出力 eval(P, v) から入力 v を復元する 4つの等価な経路が存在します。4経路の一致は、プログラム反転・自己解釈・データ符号化・ データレベル反転のコヒーレンス（整合性）を実証します。

経路A（直接反転）: eval(inv(P), eval(P, v)) = v
経路B（ri+qi往復）: qi(ri(p2d(P), v)) → 末尾 = v
経路C（inv経由ri）: ri(p2d(inv(P)), eval(P, v)) → 末尾 = v
経路D（データ反転経由）: ri(invert_data(p2d(P)), eval(P, v)) → 末尾 = v

検証済み：identity・swap プログラムにおいて、全4経路が一致することを確認。 特に経路CとDの等価性は、可換図式 p2d(inv(P)) = invert_data(p2d(P)) の実行レベル検証です。

5. Kleene不動点定理 — 可逆プログラムの自己参照

Kleeneの再帰定理は計算可能性理論の基礎です。可逆計算の文脈で不動点が存在することは、 R-WHILEが「十分に表現力がある」ことを示します。 反転不動点（自己逆プログラム）は可逆計算に固有の概念です。

不動点の種類定義結果
反転不動点inv(P) = Pidentity, X ^= nil が該当。swap, reverse は非該当
二重反転不動点inv(inv(P)) = P全プログラムが不動点（対合性）
意味的不動点eval(P, x) = eval(inv(P), x)自己逆プログラムについて有限領域で検証
注目すべき結果：CAss（可逆代入 X ^= e）は常に自己逆であり、 代入のみからなるプログラムは必ず反転不動点です。 一方、CRep（可逆置換）を含むプログラムは一般に自己逆ではありません。
