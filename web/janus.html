Janusとは？

Janus（ヤヌス）は、世界で初めて設計された可逆プログラミング言語のひとつです。 名前はローマ神話の双面神ヤヌス（過去と未来の両方を見る神）に由来しています。

普通のプログラミング言語（CやPythonなど）で書いたプログラムは、入力から出力への一方通行です。 たとえば x = 5 と書くと、それまでの x の値は上書きされて失われてしまいます。

Janusで書いたプログラムは、すべての計算を逆向きにも実行できます。 出力の値から入力の値を完全に復元できるのです。 動画の再生と巻き戻しのように、プログラムの実行を自由に前にも後ろにも進めることができます。

身近な例え：折り紙を折るとき、折る手順（順方向）を知っていれば、逆にたどって元の平らな紙に戻す（逆方向）こともできます。 でも、途中でハサミで切ってしまう（情報を失う操作）と、元に戻せなくなります。 Janusは「ハサミで切る操作」を一切使わないプログラミング言語です。

Janusについては Wikipedia（日本語） / Wikipedia（英語） も参照してください。

なぜ「可逆」が重要なのか

「プログラムを逆に動かす」ことは、一見するとただの面白い性質に見えるかもしれません。しかし、可逆計算は実際にさまざまな場面で役に立ちます。

  • デバッグ（バグ探し）：プログラムがエラーを起こしたとき、その時点から実行を「巻き戻し」て原因を探ることができます。通常のデバッガでは最初からやり直す必要がありますが、可逆プログラムなら直前の状態に戻れます。
  • 暗号：暗号化（データを秘密にする）と復号（元に戻す）は、まさに逆の操作です。可逆プログラムなら、暗号化プログラムを書くだけで、復号プログラムが自動的に得られます。
  • 量子コンピュータ：量子コンピュータの基本的な演算（量子ゲート）はすべて可逆です。そのため、可逆プログラミングの技術は量子回路の設計に直接応用できます。
  • 省エネルギー：物理法則に基づくランダウアーの原理によれば、情報を消去するときにエネルギーが消費されます。情報を消去しない可逆計算は、理論的には発熱を最小限に抑えることができます。
  • ニューラルネットワーク：RevNet（可逆残差ネットワーク）のように、可逆性を利用してメモリを大幅に節約する深層学習の手法もあります。

Janusの仕組み：普通のプログラムと何が違うの？

ルール1：代入（=）が使えない

普通の言語では x = 5 のように変数に値を代入しますが、これは元の値を上書きして消してしまいます。 Janusでは代入の代わりに、可逆な更新演算子を使います。

  • x += 5（xに5を足す）↔ 逆は x -= 5（xから5を引く）
  • x -= 3（xから3を引く）↔ 逆は x += 3（xに3を足す）
  • x ^= y（xとyのXOR）↔ 逆は x ^= y（XORは自分自身の逆）

ルール2：if文には「入口条件」と「出口条件」の両方が必要

普通のif文は「入口条件」だけですが、Janusのif文には「出口条件」（fi）も書きます。 逆実行するときは出口条件が入口条件の役割を果たすので、逆方向でも正しく分岐を判断できます。

例：2つの変数の値を交換するプログラム

Janusで x と y の値を入れ替えるプログラムは以下のようになります。

// 入力: x=3, y=5 → 出力: x=5, y=3
procedure swap
  x += y    // x = 3+5 = 8
  y -= x    // y = 5-8 = -3
  y *= -1    // y = -(-3) = 3
  x -= y    // x = 8-3 = 5

このプログラムを逆向きに実行すると、各行の操作が逆になり、下から上に実行されます。

// 逆実行: x=5, y=3 → x=3, y=5（元に戻る！）
  x += y    // x = 5+3 = 8 （-= の逆）
  y *= -1    // y = -3 　　 （*= -1 の逆は自分自身）
  y += x    // y = -3+8 = 5（-= の逆）
  x -= y    // x = 8-5 = 3 （+= の逆）
x=3, y=5
⟶ 順方向 ⟶
x=5, y=3
⟶ 逆方向 ⟶
x=3, y=5

値が完全に元に戻ることが確認できます。Janusでは、どんなプログラムでもこのように逆実行が可能です。

Janusの歴史

1982年
Christopher LutzとHoward Derbyが、アメリカのカリフォルニア工科大学（Caltech）でJanusのアイデアを考案。世界初の可逆プログラミング言語の構想が生まれる。
1986年
Lutzが Janus の言語仕様を記述した文書「Janus: a time-reversible language」を公開。
2007年
横山哲郎とRobert Glückが、Janusの操作的意味論（プログラムの動作を数学的に定義したもの）を形式化。プログラムを自動的に逆変換する「プログラムインバータ」と、自分自身を解釈実行できる「可逆自己インタプリタ」を発表。この論文がJanusの現代的な研究の出発点となる。
2008年
横山・Axelsen・Glückが「可逆フローチャート言語の基本原理」を発表。可逆言語の構造定理（すべての可逆フローチャートプログラムは構造化できる）を証明。
2016年
横山らが「可逆フローチャート言語の基礎」をTheoretical Computer Scienceに発表。可逆プログラミング言語の数学的基盤を確立。
2021年
国際会議 Reversible Computation（RC 2021）を横山が共同編集。
2023年
Glück・横山が「Reversible computing from a programming language perspective」をTheoretical Computer Scienceに発表。可逆計算のプログラミング言語的視点からの包括的なサーベイ。
現在
横山研究室では、Janusを基盤として可逆アルゴリズム、暗号、量子計算、セルオートマトンなど幅広い研究を展開中。

横山研究室の Janus 関連研究

横山研究室では、Janusを出発点として「可逆計算」に関する幅広い研究を行っています。 以下は主な研究テーマとその概要です。

可逆アルゴリズム

線形探索、深さ優先探索、文字列照合、ソートなど、基本的なアルゴリズムを可逆に設計し直す研究です。「どれだけ余分なデータが必要になるか」を理論的に解析しています。

可逆プログラミング言語の設計

Janusの後継となる新しい可逆言語（R-WHILE, ROOPL++, R-COREなど）を設計し、その数学的性質（可逆性の証明）を研究しています。

R-COREの可逆性の機械検証 →

暗号と可逆計算

暗号化と復号は逆の操作なので、可逆言語と相性抜群です。IoT向け軽量暗号（SIMON, LEA）をJanusで実装し、暗号化プログラムから復号プログラムを自動生成する研究を行っています。

暗号と可逆計算の研究テーマ →

量子計算への応用

量子コンピュータの演算は本質的に可逆です。可逆計算の技術を量子回路設計に応用し、量子加算器の最適化やメモリ管理の研究を行っています。

Janusから広がる可逆言語ファミリー

Janusの研究から、さまざまな特徴を持つ可逆プログラミング言語が生まれています。

言語名 特徴 関連プロジェクト
Janus 手続き型の可逆言語。世界初の可逆言語のひとつ。整数型変数、可逆な更新演算子、可逆if文・ループを持つ。 Rabin-Karp照合
R-WHILE 最小限の機能を持つ可逆言語。木構造データを扱い、可逆チューリング完全（どんな可逆計算でも表現可能）。理論研究向け。 R-WHILEインタプリタ
R-CORE 可逆計算の本質的構造を研究するための最小限の可逆命令型言語。証明支援系での形式検証の対象。 R-COREの機械検証
ROOPL++ 可逆オブジェクト指向言語。クラス、継承、メソッド呼び出しなどを可逆に実現。 インタプリタ（GitHub）
Hermes 暗号アルゴリズム記述に特化した可逆言語。暗号化プログラムから復号プログラムを自動生成できる。 —
CJanus Janusの並行拡張。複数のプロセスを同時に走らせながら、可逆性を保つ。Go言語で実装。 CJanusの性能評価
SyReC 可逆回路の記述と合成のためのハードウェア記述言語。可逆論理ゲート（Toffoliゲートなど）で構成される回路をプログラムのように記述でき、自動的に回路を合成できる。 論文（Integration）
