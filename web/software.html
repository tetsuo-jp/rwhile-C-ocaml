Janus Playground

可逆言語 ブラウザで実行可能

Janusは、世界で初めて設計された可逆プログラミング言語のひとつです。 すべてのプログラムを逆方向にも実行できるという特徴を持っています。

Janus Playgroundでは、ブラウザ上でJanusプログラムを書いて実行することができます。 インストール不要で、可逆プログラミングを体験できます。

  • 変数の値を「増やす」操作（+=）に対して「減らす」操作（-=）が対応
  • if文には正方向と逆方向の両方の条件が必要
  • プログラム全体を逆実行できる

Jana / Janus インタプリタ

Haskell GitHub

Janus言語のインタプリタ実装です。Haskellで書かれており、 コマンドラインから可逆プログラムを実行できます。

  • 正方向・逆方向の実行をサポート
  • Haskell Stack でビルド可能
  • 研究・教育目的で利用可能

R-WHILE インタプリタ

OCaml 可逆言語 GitHub

R-WHILEは、木構造データを扱う最小限の可逆プログラミング言語です。 可逆チューリング完全であることが証明されており、可逆自己インタプリタも存在します。

  • 正方向の実行・逆プログラムの自動生成
  • マクロ展開・プログラムの木データへの変換（P2D）
  • Alcotest による 71 件のテストスイート付き
  • ブラウザ上で実行可能な Playground を提供

ROOPL++ インタプリタ

OCaml GitHub

ROOPL++は、可逆オブジェクト指向プログラミング言語です。 横山研究室で開発されたインタプリタはOCamlで実装されており、 プログラムの逆実行（inverse）の生成にも対応しています。

  • 可逆オブジェクト指向プログラミングをサポート
  • -inverse フラグで逆プログラムを表示
  • 標準ライブラリ付き
  • Webインターフェースでブラウザからも実行可能
